
# 项目日志

## 2026-10-11-12

### 目标
在昇腾 Atlas 200I DK A2 上跑通 YOLO11 推理，并做成 Web 展示工具。

### 完成事项

1. **PC 端导出 ONNX**
   - 关键参数：`opset=12, simplify=False, dynamic=False`
   - `simplify=True` 会破坏模型结构，导致输出异常

2. **开发板 ATC 转 OM**
   - 使用开发板自带的 CANN 7.0.RC1
   - 限制并行编译：`TE_PARALLEL_COMPILER=1`
   - 生成 `yolo11n.om`

3. **推理脚本**
   - `infer_yolo.py`：单张图片推理（CLI）
   - 关键：letterbox 预处理 + 直接使用模型输出（不做 sigmoid）+ NMS + 坐标还原

4. **Web 工具**
   - `image_detect.py`：图片上传检测
   - `camera_web.py`：摄像头实时 MJPEG 流
   - 用 Python 标准库 `http.server`，无需第三方依赖

### 关键发现

**YOLO11 的 OM 输出已经是概率值，不需要 sigmoid。**

原始输出 `类别维 max = 0.9395`，直接取用即可。加 sigmoid 后所有分数挤到 0.5，argmax 随机。

### 性能

- NPU 推理：10.28 ms
- 吞吐：97 FPS
