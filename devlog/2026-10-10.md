# 项目日志：YOLO 训练与桌面应用集成

日期：2026-10-10
项目：YOLO 从训练到桌面应用全链路
参与人：AI 新手（个人项目）
项目目标：完成 Ultralytics 训练，实现实时推理部署，并接入 Web / 桌面应用。

---

一、项目概览

本项目旨在从零开始，完成 YOLO 模型的训练、推理部署以及应用集成。
技术栈：Ultralytics YOLO11n + PyTorch + FastAPI + Electron + Python 3.12。
硬件环境：NVIDIA GeForce RTX 5060 Laptop GPU，Windows 系统。

最终成果：一个可运行的 Electron 桌面应用，能够调用摄像头实时进行 YOLO 目标检测，并通过 FastAPI 与 Python 后端通信。

---

二、任务完成情况

✅ 任务一：完成 Ultralytics 一次训练

· 数据集：COCO8（官方 8 张图片小型数据集，用于快速验证流程）
· 模型：YOLO11n（nano 版本，轻量快速）
· 训练参数：
  · epochs=3（快速跑通）
  · imgsz=640
  · batch=16
  · device=0（RTX 5060 Laptop）
· 训练结果：
  · mAP50：0.886
  · 推理速度：1.9ms/图
  · 最佳模型：runs/detect/train-2/weights/best.pt

✅ 任务二：YOLO 实时推理部署（Python 版）

· 使用 opencv-python + ultralytics 实现摄像头实时推理。
· 解决了摄像头被系统锁定、OpenCV 后端选择等问题。
· 关键代码：cv2.VideoCapture(0, cv2.CAP_DSHOW) 强制使用 DirectShow 后端。
· 实现实时画框、类别显示，按 q 退出。

注：C++/Rust 性能优化暂时跳过，直接进入应用集成。

✅ 任务三：接入应用（Web + Electron 桌面）

3.1 Web 应用（FastAPI + HTML）

· 后端：backend/server.py，使用 FastAPI 提供 /detect 接口，接收图片，返回检测结果 JSON。
· 前端：frontend/index.html，浏览器调用摄像头，定时截图发送至后端，并显示检测结果。
· 跑通流程：浏览器实时检测，终端返回 200 OK。

3.2 桌面应用（Electron 内嵌）

· 架构：Electron 主进程启动 Python 后端，等待 /health 就绪后加载前端页面。
· 主进程：electron/main.js，使用 child_process.spawn 启动 yolo-env\Scripts\python.exe。
· 预加载：electron/preload.js，暴露后端地址给前端。
· 前端复用：将 Web 版 index.html 直接嵌入 Electron 窗口。
· 成功运行：Electron 窗口显示摄像头画面，实时调用 YOLO 推理，显示检测类别与置信度。

三、遇到的问题与解决方案

问题 原因 解决方案
Python 3.14 无法安装 PyTorch PyTorch 官方尚未发布适配 Python 3.14 的 wheel 降级至 Python 3.12，重建虚拟环境
NumPy 导入错误 numpy._core._multiarray_umath 虚拟环境残留 Python 3.14 编译的二进制文件 彻底删除旧 yolo-env，用 3.12 重新创建
摄像头显示“锁”图标 摄像头被其他程序占用或物理开关关闭 彻底退出微信/QQ/浏览器，检查物理开关，使用 CAP_DSHOW
npm start 报错 Cannot find module electron 项目建在了 yolo-env\Scripts 目录下 将项目移至桌面 C:\Users\LEGION\Desktop\yolo-electron
Electron 窗口闪退 BrowserWindow 局部变量被垃圾回收 声明全局变量 let mainWindow = null; 并赋值
前端报错 api_base is not defined 变量名拼写错误，未声明 统一使用 const API_BASE = ...
后端启动失败 Backend not reachable server.py 缺少 uvicorn.run() 入口 添加 if __name__ == "__main__": uvicorn.run(app, ...)
