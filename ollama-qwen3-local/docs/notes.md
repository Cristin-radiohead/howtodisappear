## 常用命令

### 模型管理
- `ollama list` — 查看已下载的模型
- `ollama pull qwen3:8b` — 下载模型
- `ollama rm qwen3:8b` — 删除模型

### 对话
- `ollama run qwen3:8b` — 进入对话模式
- `ollama run qwen3:8b "你好"` — 单次提问

### 对话内命令
- `/bye` — 退出
- `/clear` — 清空上下文
- `/show info` — 查看模型信息
